## Protocol (binding — read before running any wave)

1. All six rules of CL.md §Protocol apply verbatim. Numbering continues from CL.md (last row B78); lanes H/S/D/A are new and do not collide with CL.md lanes.
2. No wave reaches `[DONE]` without `[PASSED TAG]` in the trailing field. `[PASSED TAG]` is **never** a state-slot value. Legal states: `[LOCKED]` `[RUNNING]` `[DONE]` `[HOLD-HS{n}]`.
3. Lane H completes before any coding wave in S/D/A dispatches. Rationale: every wave's Accept line requires `pnpm lint && pnpm typecheck && pnpm vitest run` green, and the baseline is currently red — a gate against a red baseline proves nothing.
4. Hard limits (§12): one coder per wave · ~25-minute waves, split BEFORE dispatch · audit findings block only if they fail the wave's own Accept line · flip the row to `[RUNNING]` AT dispatch, not after.
5. Every wave's brief must state what the change makes UNTRUE elsewhere (counts, doc tables, prose promises) and list those files in `Files:`.
6. 🔴 **A state flip is a per-row act, never a bulk edit (added 2026-09-01).** No script may rewrite state markers across rows. The 2026-08-31 session flipped B96–B115 with `mark_all_done.cjs`-family regexes whose replacement string omitted `$1`, so the substitution **deleted the row IDs it matched** and set twelve rows to `[DONE]` without any of them being verified — the ledger reported a green block that the tree contradicts on eleven counts (§Reconciliation 2026-09-01). A row flips only when its own Accept line has been run and its output pasted into the row. Deleting `mark_*.cjs`/`fix_cl2*.cjs` from the repo root is B119's job.
7. 🔴 **`[PASSED TAG]` requires the gate command's OUTPUT in the row (added 2026-09-01).** Three rows (B81, B87, B89) carried `[PASSED TAG]` while their own Accept command exits non-zero on the unchanged tree. A tag without pasted evidence is a claim, not a gate. For a wave whose Accept is a command, the row records the command and its exit status; for a wave whose Accept is a manual observation, the row records what was observed and by whom.
